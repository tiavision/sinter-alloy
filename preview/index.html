sinter-alloy

Opinionated sinter components for what attributes cannot do, all running live below: drag a row or card by its handle (or focus it and use Space and the arrow keys), drag the split's separator, pick dates, press Ctrl+K, scroll the long list.

Sortable list

Built <alloy-sortable>

Reorder with a mouse, touch or the keyboard. The row moves at once; a self-saving use then sends the whole order in one request, and a refused one puts the row back.

Board

        Built
        <alloy-board>
      

      
Cards move within a column and between columns; Left and Right move a picked-up card to the
        neighbouring column. A self-saving use sends the target column's order with the card's new group.

      
        

          
          
        

      
      

    


    
    

      

        
Split panes

        Built
        <alloy-split>
      

      
Owns its two panes and keeps their size itself. Drag the separator, or focus it and use the arrow
        keys (Shift for bigger steps); Enter collapses the folders and opens them again; a double-click puts it back. The
        size you leave is there on your next visit.

Date, range and month pickers

        Built
        <alloy-date> <alloy-range> <alloy-month>
      

      
Dates in the page's language, whatever the browser's: this page is English, so the week starts on
        Sunday; a German page would start it on Monday and write 10.11.2026. Type a date or open the calendar; in it the
        arrow keys move by a day or a week and PageUp/PageDown by a month. A range in a real page goes to two URL
        parameters; here it goes to the page's state.

Command palette

        Built
        <alloy-palette>
      

      
Press Ctrl K (⌘ K on a Mac) or the button. It lists
        the page's own navigation and shortcut buttons with no setup (here: the Shuffle button below), the page's own
        commands (the sections of this page), and in a real app the server's answers as you type.

      

        
        
        
      

    


    
    

      

        
Long list

        Built
        <alloy-virtual>
      

      
Renders only the rows in view. Scroll it: when the view reaches the last loaded row it emits
        end, which a real page answers with page(list, 'next') over sinter's
        append pagination; here each end adds 500 generated contacts, up to 5,000.
